# Echoes of the Abyss

 An atmospheric 2D educational platformer for English as a Foreign Language (EFL) students, integrating English grammar challenges into a gothic exploration framework.


##  Overview

Players take the role of a **Mage** awakening in the *Abyssal Manor* — a shifting estate where memories have been lost. To progress and recover their identity, players navigate 2D labyrinths and overcome *Grammatical Seals*: linguistic barriers that require correct English reconstruction to unlock.



##  Gameplay Mechanics

The core loop balances platforming with educational gates:

- **Labyrinth Trials** — Navigation through segmented manor corridors
- **MCQ Seals** — Interaction with Memory Altars triggers EFL challenges to unlock paths
- **Visual Feedback** — Correct responses dynamically update scene lighting and color; errors maintain a low-visibility state
- **Narrative Progression** — Successful challenges unlock story fragments, tying grammatical proficiency to world-building



##  Educational Objectives

Focused on **contextual language application** rather than rote memorization:

- **Prepositions** — Targeted drills on place and time (*in, on, at, behind, through*)
- **Syntax** — Emphasis on tense consistency and sentence structure
- **UX Design** — Simplified controls keep cognitive load focused on language processing

##  Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/echoes-of-the-abyss.git
```

### 2. Requirements
Ensure **Unity 2022.3 LTS** is installed via [Unity Hub](https://unity.com/unity-hub).

### 3. Project Initialization
- Add the project folder in Unity Hub
- Open the project and allow the initial import process to complete

### 4. Run the Game
- Navigate to `Assets/Scenes`
- Open `MainMenu.unity` and enter **Play Mode**
